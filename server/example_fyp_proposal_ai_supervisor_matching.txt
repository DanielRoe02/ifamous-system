Project Title:
Intelligent FYP Assessment Management and Outcome System

Abstract:
This project proposes the development of an intelligent web-based Final Year Project management platform designed to support coordinators, students, supervisors, and examiners in managing the academic project lifecycle more efficiently. The system uses artificial intelligence to assist the coordinator in matching students with suitable supervisors based on project title, abstract, keywords, and lecturer expertise. The system also supports centralized project record management, student proposal tracking, timetable management, AI-assisted scheduling support, workload balancing, and dashboard monitoring.

The supervisor matching feature compares proposal content with lecturer areas of expertise such as Artificial Intelligence, Machine Learning, Data Analytics, Software Engineering, Database Systems, Academic Information Systems, Automation, and Web Application Development.

Keywords:
Artificial Intelligence, Machine Learning, Data Analytics, Supervisor Matching, FYP Management, Academic Workflow, Scheduling, Dashboard, Software Engineering, MySQL
